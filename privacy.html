TINMAN AEROFLITE

Privacy Policy

Effective for Tinman Aeroflite version 1.6.0.

Our approach

Tinman Aeroflite is a private document retrieval and summarization assistant. It has no advertising, tracking, analytics, data brokerage, or third-party AI service. Questions, answers, and retrieved approved-library excerpts remain only on the user’s device.

Information used

  • Accounts: The server stores the approved sign-in email address, role, Argon2id password hash, and revocable session records. The app stores an opaque session token and time-limited offline authorization in the device Keychain and never stores the password.
  • Authorized devices: The server stores a random app-installation identifier, device name, platform, app version, and first/last sign-in time so the owner can identify and revoke devices. It does not collect the advertising identifier.
  • Downloaded content: After sign-in, the app downloads a content-only search database and AI model from the private server. It stores both with iOS file protection, excludes them from device backups, and removes them when the user signs out or deletes the account.
  • Questions: The app searches and answers questions entirely on the device. Question and answer text is not sent to or retained by the Tinman server. The current conversation remains only in app memory.
  • Operational logs: The server stores limited account-management, authorized-device, and update events for security and operation. A network address is used temporarily to limit failed login attempts. Audit events are removed after 90 days and failed-login network addresses after 15 minutes.

The service does not sell or share this information and does not use it for tracking, advertising, analytics, or training an external AI model.

Access, correction, and deletion

The organization’s owner controls account provisioning. The owner can reset a password, revoke an individual device or active sessions, disable access, or permanently delete an account. A signed-in user can permanently delete their own account from Settings. Contact the organization’s Tinman Aeroflite owner for access or correction.

Security

The app requires encrypted HTTPS transport for authentication and verified updates. The API binds only to the Tinman server’s loopback interface. Release traffic reaches that service through a dedicated outbound-only encrypted tunnel; no public API port is opened on the server. Passwords are never stored in plaintext. A device-only offline authorization lease expires no more than 24 hours after the last successful online verification.
