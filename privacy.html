TINMAN AEROFLITE

Privacy Policy

Effective for Tinman Aeroflite version 1.1.

Our approach

Tinman Aeroflite is a private operational document assistant. It has no advertising, tracking, analytics, data brokerage, or third-party AI service. Questions, answers, and approved library excerpts remain on the organization’s Tinman server.

Information used

  • Accounts: The server stores a username, role, Argon2id password hash, and revocable session records. The app stores only an opaque session token in the device Keychain and never stores the password.
  • Authorized devices: The server stores a random app-installation identifier, device name, platform, app version, and first/last sign-in time so the owner can identify and revoke devices. It does not collect the advertising identifier.
  • Questions: Question text is sent to the Tinman server solely to retrieve approved evidence and generate an answer. Question and answer text are not retained in the audit log. The current conversation remains only in app memory.
  • Operational logs: The server stores limited account-management and answer-status events for security and operation. A network address is used temporarily to limit failed login attempts. Audit events are removed after 90 days and failed-login network addresses after 15 minutes.

The service does not sell or share this information and does not use it for tracking, advertising, analytics, or training an external AI model.

Access, correction, and deletion

The organization’s owner controls account provisioning. The owner can reset a password, revoke an individual device or active sessions, disable access, or permanently delete an account. A signed-in user can permanently delete their own account from Settings. Contact the organization’s Tinman Aeroflite owner for access or correction.

Security

The app requires encrypted HTTPS transport. The API and local AI agent bind only to the Tinman server’s loopback interface. Release traffic reaches that service through a dedicated outbound-only encrypted tunnel; no public API port is opened on the server. Passwords are never stored in plaintext.
