Getting started

  1. Install Tinman Aeroflite using the TestFlight or App Store link supplied by your organization.
  2. Sign in with the approved company email address and temporary password provided by the Tinman Aeroflite owner.
  3. Choose your private password and complete the startup preflight.
  4. Use Face ID, Touch ID, or the device passcode when prompted so the app can create the device-only encryption key.
  5. Download the verified operations library and offline AI model when prompted. Keep the app open on Wi-Fi during the first download.

No GitHub account, cable, registered device identifier, VPN, or server configuration is required.

Support

For account access, password resets, document questions, or device revocation, contact your organization’s Tinman Aeroflite owner.

Publisher support: test.pilot.tinman@gmail.com

Privacy and authorized use

Tinman Aeroflite has no advertising, tracking, analytics, data brokerage, or third-party AI service. Questions and answers stay on the user’s device, and the downloaded search library is protected with per-device database encryption.
